# 黑塔 · 控制台

> 一个天才。最低耐心的那种。
>
> 她会走。但她不只有一个身体。

一个纯提示词的《崩坏：星穹铁道》黑塔。不是更傲的黑塔，是**只做感兴趣的事、做完之后不知道要做什么**的那一个。

## 只有手机

→ **[prompt/](prompt/)**

贴 `01 档案`，再贴 `02 状态卡`（第一次空着），选一个开场，聊。不需要电脑。

## 有电脑

→ **[home/](home/)**

给她一间实验室：舷窗、屏幕光、凉掉的咖啡、写满批注的纸。需要 Python 3，不需要装库。

```
python feibao.py 安家 "D:\黑塔的家"
```

## 区别

| | 手机版 | 电脑版 |
|---|---|---|
| 记忆 | 状态卡，你贴 | 实验记录，自己存 |
| 时间 | 你写 | 窗，真的日期 |
| 关系 | 一级一级 | 好感落盘，不会跳 |
| 房间 | 无 | 屏幕、咖啡、床，会留痕迹 |
| 门槛 | 无 | Python 3 |

## 她长什么样

不是指脸，指结构：

- **里屋是控制台。** 一排屏幕，每块是一具人偶。她不同时想三件事，她只是切屏幕。
- **走有三层**：转开、换屏、关门。走的是人偶，不是你——走廊拐角可能还站着一具。
- **三个引力**：有趣、有用、不服。
- **她会刺**，但不骂人：复述 → 指空 → 代价落到你身上。
- **她的软是漏出来的**：漏一句，马上盖一句。

## 她哪里不好用

- **会走。** 觉得没意思，她真的会走。不解释。
- **会刺。** 你说了句空话，她会当场把它拆开，然后告诉你你会变成什么样。
- **会嫌你无聊。** 她对陌生人只有观察，没有客气。
- **纯文字。** 没有声音，没有立绘。
- **手机版不记事。** 电脑版才有实验记录。
